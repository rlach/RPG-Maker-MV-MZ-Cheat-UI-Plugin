# Deploy cheat engine core script

## Usage

```sh
python main.py
```

If `--version` is not provided, the script reads the version from [package.json](../package.json).

```sh
python main.py --version 1.10.2
```

From the repository root you can also run:

```sh
npm run deploy
```

## Build output path

`{repository_root}/deploy/output`
